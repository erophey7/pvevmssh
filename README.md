# PVE SSH Server

**SSH-сервер для удалённого доступа к serial-портам виртуальных машин Proxmox VE и управления инфраструктурой.**

Проект находится в активной разработке. API и функциональность могут меняться.

---

## 🧭 Roadmap

### ✅ Реализовано (MVP)
- [x] **Примитивный SSH-сервер** с поддержкой PTY
- [x] **Система команд** (категории, одиночные команды, команды-пакеты)
- [x] **Загрузка команд** из директории `commands/`
- [x] **Наследование прав** (категории → команды)
- [x] **Конфигурация** в JSON (порт, host key, права групп)
- [x] **Аутентификация** (заглушка — принимает любые логин/пароль)
- [x] **Управление сессиями** (контекстная переменная, хранилище)
- [x] **Окружение пользователя** (`UserEnvironment`: set, get, unset, substitute)
- [x] **PTYHandler** с `spawn()` (автоматическая настройка управляющего терминала)
- [x] **Поддержка мыши** (режимы 1000/1002/1003/1006, колёсико)
- [x] **Тестовые команды**: `chars`, `color`, `mouse`, `whoami`, `echo`, `export`, `about`, `sessions`, `bash`
- [x] **Полноценный line editor** (история, word-навигация, Ctrl+W/Ctrl+Delete)

### 🚧 В процессе / ближайшие задачи
- [ ] **Интеграция с API Proxmox** (аутентификация по API-ключу)
- [ ] **База данных** (абстрактный слой, поддержка SQLite и MariaDB)
- [ ] **Хранение API-ключей** с шифрованием через SSH-ключи пользователя
- [ ] **Реальная аутентификация** (пароли, ключи, API-ключи Proxmox)
- [ ] **Агенты на нодах Proxmox** (запуск от root, работа с сокетами VM)

### 📌 Планируется
- [ ] **Команды для работы с ВМ**: `list`, `start`, `stop`, `migrate`, `status`
- [ ] **Подключение к serial-порту** ВМ через команду `terminal <vmid>`
- [ ] **Протокол между сервером и агентами** (сырой TCP, возможно protobuf/msgpack)
- [ ] **Расширенная система прав** (на основе ролей Proxmox)
- [ ] **История команд** в базе данных
- [ ] **Автодополнение команд** (readline / prompt-toolkit)
